Folder structure:
bharat-temple-website/
  index.html
  temples.html
  temple.html
  about.html
  contact.html
  css/style.css
  js/temples.js
  js/app.js

HOW TO RUN:
1. ZIP extract karein.
2. Folder open karein.
3. index.html par double-click karein, ya VS Code mein folder open karke Live Server se index.html run karein.
4. All Temples page par 64 temples ki list milegi.
5. Kisi card par "पूरी जानकारी" click karne se temple.html par us mandir ki detail khulegi.

IMPORTANT:
- Search, state filter, category filter aur detail pages JavaScript se kaam karte hain.
- Contact form abhi demo hai; actual email bhejne ke liye backend/form service chahiye.
- Religious beliefs are presented as beliefs/traditions, not scientifically verified powers.
- Kuch dates/periods approximate hain; public launch se pehle ASI/state tourism/temple trust sources se verify karein.
